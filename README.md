# Sudhanraja S — Portfolio (3D Creator style)

Dark, motion-heavy single page built with React, TypeScript, Tailwind CSS, Framer Motion and Lucide React.

Sections: Hero (magnetic cut-out portrait) → screenshot Marquee (scroll-driven) → About (scroll-revealed text + CSS 3D shapes) → Skills (white sheet) → Projects (sticky stacking cards) → Experience → Contact (Formspree form).

All copy, links and images live in `src/data/portfolio.ts`.

```bash
npm install
npm run dev     # local dev
npm run build   # type-check + production build
```

`public/portrait.webp` is the background-removed hero photo. Replace it with any transparent PNG/WebP to change the hero.
